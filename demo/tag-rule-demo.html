INTERACTIVE DEMO — simulated data only; nothing reads your machine

Does your browser tag match your ActivityWatch rule?

Every browser profile stamps a client tag onto its window titles (via the URL-in-Title extension), and ActivityWatch classifies those titles with per-client regex rules. If the tag format and the rule disagree, nothing matches — silently. This demo lets you push realistic window titles through a tag convention and a set of rules, and see exactly which titles categorise where, which fall through, and which land on the wrong client. The plugin now writes those rules for you and refuses one that matches nothing or matches half your day — this is what it is refusing, and why a profile tag belongs only on a browser profile dedicated to a single client. All clients and URLs here are fictional.
